# Biblioteca Digital UniFECAF

## Sobre o projeto

Este projeto foi desenvolvido para a disciplina de **Design Web da UniFECAF**, com o objetivo de transformar um protótipo de baixa fidelidade em uma interface web moderna, responsiva, acessível e alinhada à identidade visual da instituição.

A Biblioteca Digital UniFECAF foi criada para facilitar o acesso dos estudantes a informações sobre livros, materiais acadêmicos e serviços oferecidos pela biblioteca.

## Tecnologias utilizadas

- HTML5 — estruturação do conteúdo.
- CSS3 — estilização, layout e responsividade.
- Visual Studio Code — ambiente de desenvolvimento.
- Git e GitHub — versionamento e armazenamento do código.

## Funcionalidades e seções

O site apresenta:

- Menu de navegação.
- Banner de apresentação da biblioteca.
- Seção "Sobre a nossa biblioteca".
- Catálogo com seis livros.
- Informações sobre as unidades.
- Seção de contatos.
- Layout responsivo para computadores, tablets e smartphones.

## Identidade visual

O projeto utiliza cores inspiradas na identidade visual da UniFECAF, com predominância de azul e verde e detalhes em amarelo.

A interface apresenta elementos ilustrados, cartões de livros e uma mascote chamada Livi, proporcionando uma experiência visual mais descontraída e acolhedora.

## Responsividade e acessibilidade

O site foi desenvolvido para se adaptar a diferentes tamanhos de tela, utilizando CSS Grid, Flexbox e Media Queries.

Também foram considerados princípios de acessibilidade, como estrutura HTML
